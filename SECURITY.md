# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < latest| :x:                |

## Reporting a Vulnerability

Security issues in SkyOS should be reported via GitHub Issues with the `security` label.

For critical vulnerabilities, please email the maintainers directly or open a draft security advisory on GitHub.

We aim to acknowledge reports within 48 hours and provide a timeline for a fix within 5 business days.
