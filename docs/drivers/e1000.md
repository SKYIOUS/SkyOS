# Intel e1000 Network Driver

The Intel e1000 driver (`kernel/kernel/src/drivers/net/e1000.rs`) provides networking for Intel Gigabit Ethernet adapters, adapted to smoltcp.

## Implementation

```rust
pub struct E1000 { base_addr: usize, /* ... */ }
impl E1000 {
    pub unsafe fn new(base_addr: usize) -> Self;  // MMIO BAR base
    pub fn read_reg(&self, offset: u32) -> u32;
    pub fn write_reg(&self, offset: u32, value: u32);
    pub fn init(&mut self);
}

pub struct E1000Device;        // impl smoltcp phy::Device (RxToken/TxToken)
pub struct E1000RxToken;
pub struct E1000TxToken<'a>;
```

## Register Layout

The driver maps the e1000's MMIO BAR (from PCI enumeration) into the physical-memory offset and accesses registers via `read_reg`/`write_reg` (`REG_CTRL`, `REG_STATUS`, `REG_EEPROM`, `REG_ICR`, `REG_IMS`, `REG_RCTL`, `REG_TCTL`, etc.). The MAC address is read from the EEPROM register region.

## Initialization

1. Reset the hardware
2. Allocate transmit and receive descriptor rings
3. Read the MAC address
4. Configure receive/transmit control registers
5. Enable DMA and interrupts

## smoltcp Integration

`E1000Device` implements smoltcp's `phy::Device` trait, with `E1000RxToken`/`E1000TxToken` exposing the ring buffers as `RxToken`/`TxToken`. The net feature compiles the driver and registers the device with the interface layer.

## Link Management

Link state is read from the status register; speed/duplex negotiation is handled by the hardware and reflected in the status register.
